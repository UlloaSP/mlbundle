# MLbundle identity

Original mark copied unchanged from `eshkra/src/assets/marks/mlbundle.png`
(708 × 960). The PNG retains its original resolution and embedded provenance.

Outlined wordmarks use Mona Sans from the family's self-hosted Latin subset: ML at
weight 800 and width 125%, bundle at weight 300 and width 100%, matching MLform and
MLschema glyph for glyph. Font license: SIL OFL 1.1, included alongside these assets.
Wordmarks are SVG paths so GitHub and PyPI need no fonts. `wordmark-light.svg` is
graphite `#0b0b10` for light backgrounds; `wordmark-dark.svg` is `#f4f4f6` for dark ones.

Use orange #ff6a1a with graphite and neutral backgrounds. Use MLbundle for the brand
lockup; keep `mlbundle` lowercase in package names, imports, commands, URLs and the
`.mlbundle` file extension.
